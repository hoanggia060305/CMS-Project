* ReactJS

## Cách chạy Backend

1. Mở Solution bằng Visual Studio 2022
2. Chọn CMS.Backend làm Startup Project
3. Nhấn F5

Backend chạy tại:

https://localhost:7072

Swagger:

https://localhost:7072/swagger

## Cách chạy Frontend

Mở Terminal:

```bash
cd cms.frontend
npm install
npm start
```

Frontend chạy tại:

http://localhost:3000
